# VegaBeamTool 操作手册

面向 **Daheng Mercury3** 与 **Tucsen LiraUV** 双相机光束分析上位机。

---

## 1. 软件简介

VegaBeamTool 用于：

- 打开/关闭相机，连续采图或单帧采集
- 实时显示光斑图像与轮廓
- 计算光束中心、半径、长/短轴、倾角
- 显示 4 路剖面曲线
- 记录多组坐标并在图像上叠加
- 保存 16bit TIFF 原始图

**两种相机共用同一套界面和算法**，仅在 Config 区通过 **Camera Model** 下拉框切换型号。

---

## 2. 首次使用前准备

### 2.1 通用环境

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10/11，64 位 |
| 运行时 | .NET 8（Windows Desktop） |
| 程序架构 | **x64**（两家 SDK 原生库均为 64 位） |

### 2.2 大恒 Mercury3

1. 安装 **Galaxy 相机驱动/SDK**
2. 用 USB 或网口连接相机
3. 确认 Galaxy 官方工具能识别设备

### 2.3 Tucsen LiraUV

1. 安装 **TUCam SDK（x64）**
2. 安装 SDK 自带运行库：`redist\vcredist_2013_x64.exe`
3. 默认 DLL 路径：`C:\Program Files (x86)\TUCam_SDK\runtime\x64\TUCam.dll`
4. 若安装在其他位置，可设置环境变量：

   ```
   TUCAM_SDK_PATH = <包含 TUCam.dll 的目录>
   ```

### 2.4 启动程序

- **Visual Studio**：将 `VegaBeamTool` 设为启动项，F5 运行
- **命令行**：

  ```
  dotnet run --project VegaBeamTool.csproj
  ```

- **直接运行**：`bin\Debug\net8.0-windows\VegaBeamTool.exe`

程序会在当前目录生成/读取配置文件 **`ToolConfig`**（无扩展名）。

## 3. 界面布局

```
┌─────────────────────────────────────────────────────────────┐
│  Coordinate Record │         Beam Image（主图像区）          │
├─────────────────────────────────────────────────────────────┤
│  Beam 参数表（Center/Radius/Axis/TiltAngle）                 │
├──────────────────┬──────────────────────────────────────────┤
│  Camera Control  │  Config（型号/设备/曝光/增益/路径等）     │
└──────────────────┴──────────────────────────────────────────┘
                                    │ Beam Profiles（4 条曲线）│
```

| 区域 | 作用 |
|------|------|
| **Beam Image** | 实时伪彩色光斑图，可缩放/拖拽，鼠标悬停显示像素灰度值 |
| **Coordinate Record** | 记录/删除光束中心坐标，叠加到图像 |
| **Beam** | 实时显示中心、半径、长/短轴、倾角 |
| **Beam Profiles** | 切向/径向/长轴/短轴 4 条剖面曲线 |
| **Camera Control** | 开关相机、连续采图、单帧、存图 |
| **Config** | 型号选择、设备扫描、参数与路径配置 |

## 4. 标准操作流程（两种相机通用）

推荐按以下顺序操作：

```
选型号 → 扫设备 → 选设备 → 填参数 → 开相机 → 连续采图/单帧 → 分析/存图 → 关相机
```

### 步骤 1：选择相机型号

在 Config 区 **Camera Model** 下拉框选择：

- **Daheng Mercury3** — 大恒相机
- **Tucsen LiraUV** — Tucsen 相机

> **注意**：切换型号前必须先点 **StopCamera**。相机打开时型号下拉框会被禁用。

### 步骤 2：扫描并选择设备

1. 点击 **Scan** 扫描在线相机（需 1～3 秒）
2. 在 **Device** 下拉框选择目标设备

扫描结果示例：

- 大恒：`[0] Mercury3-xxx (SN12345678)`
- Tucsen：`[0] LiraUV-RG`（打开相机后会自动读取 SN 并回填到 SN 框）

若提示 **No camera detected**：

- 检查线缆/驱动
- 确认没有其他程序占用相机
- Tucsen 可先运行自检工具（见第 8 节）

### 步骤 3：设置参数

| 参数 | 说明 | 单位/范围 |
|------|------|-----------|
| **SN** | 大恒可手填 SN；Tucsen 打开后自动回填 | 文本 |
| **ExposureTime(us)** | 曝光时间 | **微秒 μs**（两种相机界面统一） |
| **GlobalGain** | 增益 | 整数，SaveConfig 时会校验范围 |
| **Coefficient** | 像素→物理尺寸换算系数 | 默认 1.0 |
| **Average Times** | 实时显示滑动平均帧数 | ≥1，越大越平滑、延迟越高 |
| **SelectSaveImagePath** | 存图目录 | 需先选择有效路径 |

### 步骤 4：打开相机

点击 **StartCamera**。

成功标志：

- **StartCamera** 变灰，**StopCamera / Capture / Snapshot / SaveImage** 可用
- 图像区开始可显示（需再点 Capture 或 Snapshot）

失败时常见提示：

- `Please scan and select a camera device` — 未扫描或未选设备
- `Start camera failed` — 设备被占用、SN/索引错误或驱动异常
- Tucsen SDK 缺失 — 会提示安装 TUCam SDK

### 步骤 5：采集图像

| 按钮 | 作用 | 使用场景 |
|------|------|----------|
| **Capture** | 连续采图并实时分析 | 日常观测、调参 |
| **Snapshot** | 按 Average Times 次数抓若干帧并分析 | 单次测量 |
| **SaveImage** | 抓一帧并保存 16bit TIFF | 原始数据存档 |

存图文件名格式：`年_月_日_时_分_秒.tif`，保存在已选路径下。

### 步骤 6：记录坐标（可选）

1. 在 **Beam** 区确认当前中心坐标
2. 点击 **Coordinate Record** 区 **Record**
3. 记录会出现在左侧表格，图像上叠加对应标记
4. 表格右键可删除记录

### 步骤 7：保存配置（可选）

设置完成后点 **SaveConfig**，参数写入 `ToolConfig`，下次启动自动加载。

保存内容：SN、存图路径、曝光、增益、系数、平均帧数、**相机型号**。

### 步骤 8：关闭相机

1. 若正在连续采图，无需单独停 Capture，直接 **StopCamera** 即可
2. 关闭程序前建议先 **StopCamera**，确保 SDK 资源释放

## 5. 大恒 Mercury3 专用说明

| 项目 | 说明 |
|------|------|
| 设备选择 | 推荐 Scan + Device 下拉；也可在 **SN** 框手填序列号后直接 StartCamera |
| 像素格式 | 程序内部固定 **Mono12**（16bit 存储） |
| 网络相机 | 若打开失败且曾占用，可等待数秒后重试 |

---

## 6. Tucsen LiraUV 专用说明

| 项目 | 说明 |
|------|------|
| 设备选择 | **必须** Scan 后在 Device 下拉框选择（按索引 `[0]`、`[1]`… 打开） |
| SN 框 | 打开相机后自动读取；扫描阶段可能为空，属正常 |
| 曝光单位 | 界面仍为 **μs**，程序内部自动换算为 TUCam 的 ms |
| 图像格式 | 程序会尽量配置为**单色高位深**，以兼容光束分析链路 |

若打开成功但 **Capture 无图像**：

1. 先运行 Tucsen 自检工具确认能取帧（第 8 节）
2. 适当增大曝光时间（如 10000 μs = 10 ms）
3. 查看日志：`Logs\<日期>.log`

## 7. 光束分析结果说明

**Beam 区实时数值**（经 Coefficient 换算后）：

| 字段 | 含义 |
|------|------|
| Center X / Y | 光斑中心坐标 |
| Radius X / Y | 等效半径 |
| LongAxis / ShortAxis | 椭圆长轴/短轴 |
| TiltAngle | 椭圆倾角 |

**Beam Profiles 四条曲线**：

1. Tangential Beam Profile — 切向剖面
2. Radial Beam Profile — 径向剖面
3. Long Beam Profile — 长轴剖面
4. Short Beam Profile — 短轴剖面

每条曲线含原始数据与拟合曲线。

**图像交互**：

- 滚轮缩放、拖拽平移
- 鼠标悬停显示该点 **16bit 灰度值**

## 8. Tucsen 连通性自检（推荐首次接相机时执行）

在工程根目录执行：

```
dotnet run --project Tools\TucsenProbe\TucsenProbe.csproj
```

正常输出应包含：

1. `found TUCam.dll in: ...`
2. `camera count = 1`（或更多）
3. 设备型号、SN
4. 曝光/增益/位深范围
5. 连续 3 帧的宽高、`elemBytes`、`channels`

**重点关注**：

- `channels = 1` — 单色，可直接用于当前光束分析
- `channels ≠ 1` — 彩色出图，需额外转灰度（当前版本未做）
- `elemBytes = 2` — 16bit，与存图/分析链路一致

## 9. 常见问题

### Q1：Visual Studio 里选不了启动项？

- 确认启动项目为 **VegaBeamTool**
- 若仍异常：右键项目 → **重新加载项目**，或重启 VS

### Q2：Scan 扫不到相机？

| 检查项 | 大恒 | Tucsen |
|--------|------|--------|
| 驱动/SDK | Galaxy 驱动 | TUCam SDK + VC2013 运行库 |
| 占用 | 关闭厂商自带工具 | 关闭 Tucsen 官方 Demo |
| 权限 | — | 以管理员身份试一次 |
| 线缆 | USB/网口 | USB/相应接口 |

### Q3：StartCamera 失败？

- 先 **StopCamera**，再 Scan → 选设备 → 重试
- 大恒：核对 SN 是否与 Device 列表一致
- Tucsen：确认 `TUCam.dll` 存在（见 README 查找顺序）

### Q4：有图像但 Beam 参数全为 0？

- 曝光过小/过大，调整 **ExposureTime**
- 光斑过弱或过饱和，调整 **GlobalGain**
- 增大 **Average Times** 观察是否稳定

### Q5：SaveImage 无效？

- 必须先 **SelectSaveImagePath** 选择有效目录
- 目录需有写入权限

### Q6：切换相机型号后参数乱了？

- 两种相机曝光/增益范围不同，SaveConfig 会按当前相机校验
- 建议每种相机分别 SaveConfig 一次，或手动调整后再保存

### Q7：程序异常退出后相机打不开？

- 关闭所有 VegaBeamTool 进程
- 关闭占用相机的其他软件
- 重新 Scan → StartCamera

日志位置：程序目录下 **`Logs\yyyy-MM-dd.log`**

## 10. 两种相机差异速查

| 功能 | Daheng Mercury3 | Tucsen LiraUV |
|------|-----------------|---------------|
| 型号选项 | Daheng Mercury3 | Tucsen LiraUV |
| 推荐选设备方式 | Scan + Device，或手填 SN | Scan + Device（必须） |
| 曝光界面单位 | μs | μs（内部换算） |
| 连续采图 | 支持 | 支持 |
| 单帧/存图 | 支持 | 支持 |
| 光束分析 | 支持 | 支持 |
| 坐标记录 | 支持 | 支持 |
| 配置保存 | 支持（含型号） | 支持（含型号） |
| 温控/Binning/ROI 等 | 当前版本未做 | 当前版本未做 |

## 11. 推荐日常操作清单

**大恒 Mercury3**

```
Camera Model = Daheng Mercury3
→ Scan → 选设备（或手填 SN）
→ 设 ExposureTime / GlobalGain
→ SelectSaveImagePath
→ SaveConfig
→ StartCamera → Capture
→ 观察 Beam + Profiles
→ 需要时 SaveImage / Record
→ StopCamera
```

**Tucsen LiraUV**

```
确认 TUCam SDK 已安装
→ Camera Model = Tucsen LiraUV
→ Scan → 选 [0] LiraUV-RG
→ 设 ExposureTime / GlobalGain
→ SelectSaveImagePath → SaveConfig
→ StartCamera → Capture
→ 观察 Beam + Profiles
→ 需要时 SaveImage / Record
→ StopCamera
```
